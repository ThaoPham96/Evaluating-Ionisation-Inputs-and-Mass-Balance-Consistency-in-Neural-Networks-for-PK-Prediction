STANDALONE MASS-BALANCE EXPERIMENT: COMPLETED METHODS

1. Scientific question and cohort
The intervention is a soft squared penalty on inconsistency among predicted
half-life, volume and clearance. No categorical ionisation input is used.
The frozen cohort has 952 labelled structures and 674 complete triads retained
from a common source row. Endpoint counts: half-life 902, V 710, CL 689, F 440,
PPB 805, Cmax 550, Tmax 686. PPB includes 24 zero values (781 positive).
The snapshot, measured values, masks, structure identity decisions, source rows
and provenance links are in data/. Full reviewed components enter model graphs.

2. Split and independence
There are 552 connected parent/scaffold groups (largest 88 structures). Explicit
spectator identities determine grouping parents. Shared normalized parent,
source-parent, standard InChI connectivity or generic active-component scaffold
links join structures transitively. Stereo/isotope variants stay in one group;
acyclic structures use parent grouping. Read data/grouping_policy.json for the
exact rules and capped tautomer-enumeration caveat. Model graphs retain full
components. The bundled pipknet/PyG graph recipe does not explicitly encode all
stereo/isotope distinctions present in the reviewed structures; Chemprop uses
its own native molecular features, including stereochemistry channels.
Five outer folds have 190,190,191,190,191 structures. Each outer training set has
five inner folds. Seed-42 deterministic group-size balancing uses no endpoint
values or missingness. Thirty overlap checks passed. These are nested grouped
cross-validation results, not an untouched external test.

3. Models and inputs
Primary: two-layer GraphConv; Chemprop 1.6.1 D-MPNN with the shared trainer;
frozen seyonec/PubChem10M_SMILES_BPE_450k representations and a two-layer MLP.
Transformer/tokenizer commit: c18fccd09b3326bf2d4633412c256d7db872156d.
Embeddings are 768-dimensional final hidden-state means, excluding padding and
special tokens. No truncation or unknown tokens occurred; maximum sequence length
403 versus limit 510, including special tokens. Only the MLP is trained in the ChemBERTa arm.
Production code hashes are in campaign/campaign.json. Full graph and feature
recipes are recorded in features/manifest.json and analysis/pipknet/featurizers.py.

4. Targets and losses
Positive endpoints (half-life h, V L, CL L/h, Cmax micromolar, Tmax h) use log10.
F/PPB use log10(p/(100-p)), clipping to [0.1,99.9] for training only; physical
scoring preserves original zero/100 labels. Each fit uses its training-only
transformed means and population SDs for standardisation. No inherited magnitude
filter is applied. Missing observations are masked separately by endpoint.
Let q=(log10(t_half),log10(V),log10(CL)), a=(1,-1,1), c=log10(ln(2)), r=a.q-c.
Loss = equal mean of observed-endpoint masked z-MSEs + lambda * mean(r^2).
The penalty uses inverse-standardised log10 predictions, never z-scores, and
uses all training structures, including those without a complete observed triad.
The primary supervised weights are all one. Validation aggregates squared-error
sums and counts over the whole partition before averaging endpoint MSEs.

5. Nested selection and seeds
Twenty predeclared configurations per primary model/outer fold are searched at
lambda=0 across all five inner folds (search seed 0). The candidate CSV is the
authoritative grid. Select equal-endpoint validation z-MSE, then hold non-loss
settings fixed. Calibrate positive lambdas 0.03,0.1,0.3,1,3,10 on the five inner
folds; reuse the chosen lambda-zero candidate's fits.
Select positive lambda using pooled inner complete same-row triad macro log-MAE.
Ties within 1e-8 choose the smaller lambda (configuration ties choose lower ID).
This main intervention requires lambda>0. A separately reported zero-eligible
policy allows baseline to win on the same inner scores.
AdamW, batch 64, float32, gradient norm clipping 1, constant candidate learning
rate, maximum 200 epochs, patience 30 and minimum improvement 1e-4 are used.
Early stopping follows unpenalised supervised validation error. Final epochs
are the rounded median of five inner best epochs, separately per loss arm.
Baseline and selected-positive policies use seeds 101,202,303,404,505,606,707,808,909.
Fixed-lambda curves use seeds 101,202,303. Matching initial parameters and random
batch/dropout streams are used across loss arms for each model/fold/seed.
Settings are baseline-tuned; the study does not independently optimise every
constrained architecture. Outer labels never determine lambda, alpha or epochs.

6. Post-hoc controls
Apply corrections to the baseline log predictions:
Orthogonal: q_alpha = q - alpha*a*r/3.
Half-life-only: q_half,alpha = q_half - alpha*r; keep V and CL unchanged.
Both yield residual (1-alpha)*r. Alpha is selected from 0,0.1,0.25,0.5,0.75,0.9,1
using inner complete-triad log-MAE, separately per method/model/outer fold;
ties choose the smaller alpha. Selected alpha is shared across final seeds.
Exact alpha=1 is also reported. It forces consistency by construction. Other
four endpoints are unchanged. Fixed-alpha curves use the first three seeds;
selected and exact policy summaries use all nine. Alpha can select zero, unlike
the required-positive lambda intervention; the zero-eligible lambda policy is
therefore a useful additional comparison.

7. Included analysis
Pool the five outer prediction folds within each seed, calculate metrics, then
average metrics across seeds. Never average predictions before these scores.
Primary accuracy is mean absolute log10 error across the three endpoints on
674 complete same-row triads. Endpoint-level accuracy uses all available labels
for that endpoint, which is a different denominator and sometimes a different
observed-label source than the complete-triad truth.
Consistency on all 952 structures is |r| <= log10(1.25), also reported at twofold,
with median |r| and median 10^|r|. Invalids count against consistency denominators;
paired accuracy uses a common finite mask and records invalid counts. All primary
predictions in this run are finite.
Five endpoint MAEs are in log10 units; F/PPB MAEs are percentage points. Relative
endpoint changes are dimensionless; do not form a macro average of these mixed
absolute units. The included scorer currently reports MAE and consistency;
RMSE, correlations, R-squared and fold-error statistics remain additional work.

8. Uncertainty
10,000 paired resamples of 552 parent/scaffold groups, PCG64 seed 20261112, retain
every member of each sampled group with multiplicity. The same resamples apply
to every compared arm/seed. Calculate a paired delta per seed, then average nine
deltas for each draw. Percentile 95% intervals condition on the fitted models,
not retraining. Seed SD is descriptive seed variation, not a confidence interval.
The included bootstrap covers selected-positive and both selected-alpha policies.
It does not provide fixed-curve or exact-projection confidence intervals.

9. Supplementary training scope
GIN/GAT/AttentiveFP, GraphConv depth 1-5 and V/CL-priority weights (5 versus 1 for
other tasks) use transferred GCN settings/lambda, with their own inner epoch
calibration and three final seeds. Matching depth-two fits are reused.
Independent single-task GraphConvs search width {64,128,256} x learning rate
{0.0003,0.001}, dropout .1, weight decay .0001, depth 2, two-layer heads; six
configurations x five inner folds per endpoint/outer fold, three final seeds.
These blocks completed but their detailed comparative analysis is not yet included.
Counts: 1500 primary search + 450 lambda calibration + 495 primary final +
240 alternative encoders + 320 additional depths + 1050 single-task search +
105 single-task final + 80 task-weight sensitivity = 4240 fits.
