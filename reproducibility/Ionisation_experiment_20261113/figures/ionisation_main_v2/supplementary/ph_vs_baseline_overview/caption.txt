Relative changes in held-out MAE for seven categorical input arms versus the same backbone's structure-only reference (REF0), on the 327-structure numerical-pKa subset with 238 parent/scaffold groups. Columns show the seven endpoints and their labelled structure counts. Each cell is the mean of nine paired MAE differences divided by the fixed nine-seed mean REF0 MAE for the same backbone and endpoint, multiplied by 100. Each seed pools its five held-out outer folds. Negative values indicate lower error. MAE uses log10 units for half-life, Vd, CL, Cmax and Tmax, and percentage points for F and PPB. The pH 6.5 comparison is descriptive. The plotted-data CSV includes exploratory 95% crossed seed/group bootstrap intervals from 10,000 draws. Grey row labels mark repeats of the pH 7.4 category, which change input parameterisation while preserving category information. Comparisons against REF0 describe the complete input representation. Figure S6 compares the four-pH input with a width-matched control. All models use zero mass-balance penalty and equal endpoint weights.
