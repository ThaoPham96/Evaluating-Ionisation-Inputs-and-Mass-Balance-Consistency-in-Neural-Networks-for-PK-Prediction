# Data provenance and source terms

The public scientific payload preserves the historical modelling values, source-row identifiers, endpoint provenance, identity masks and grouped splits. Review-time sources were used to check identity and provenance; their newer PK values were not substituted into the frozen dataset.

The e-Drug3D website's [terms, clause 6](https://chemoinfo.ipmc.cnrs.fr/Terms_of_Use.html) allow attributed copying, modification and distribution, subject to the remaining terms and any express exceptions. Commercial use requires a license. This is the relevant noncommercial reuse route for website content covered by that grant. The separately checked [e-Drug3D 2162 Zenodo deposit](https://zenodo.org/records/22831843), DOI 10.5281/zenodo.22831843, declares CC BY 4.0. That grant applies to the deposited release; it is not evidence that the original modelling extract was acquired from that deposit. The historical release remains unrecorded.

The [ChEMBL FAQ](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/general-questions) specifies CC BY-SA 3.0 for database content and separately qualifies properties calculated by commercial software. See also [ChEMBL attribution guidance](https://chembl.github.io/chembl-licensing/). Preserve those qualifications when reusing the 327 archived acid/base descriptor pairs. This research predicts PK endpoints; it does not train a replacement pKa calculator. That distinction is not a blanket waiver of commercial-calculator terms. Missing historical settings are a provenance limitation, not evidence of a general redistribution prohibition.

The 494 class labels have heterogeneous evidence, including literature values, permanent charges and structural site assessments. The accompanying ledger and source IDs identify these assignments. Original row IDs are archival identifiers; an identity match does not establish an exact original study for every endpoint. The curated targets combine source summaries across routes and studies.

The original ChemBERTa feature manifest pins model `seyonec/PubChem10M_SMILES_BPE_450k` at revision `c18fccd09b3326bf2d4633412c256d7db872156d`. The model API did not provide a license tag at that revision during the 14 November 2026 audit. Cached numerical features are included; pretrained model weights are not. Absence of model license metadata is not interpreted as either a permissive weight license or a prohibition on author-generated feature arrays.

Numerical labels and descriptors retain source-specific terms. Author software notices, generated predictions and curated assignments must not be used to relicense the underlying external resources. Compact evidence and first-party URLs are recorded in `reproducibility/source_terms_evidence.json`.
